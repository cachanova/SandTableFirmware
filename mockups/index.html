Sisyphus UI — Design Mockups

Three directions for modernizing the sand table's web UI. All use fake data; the live table viz, controls, and library are representative of the real dashboard.

AAtelier — warm, light, gallery-like

Light sand-and-paper palette with a terracotta accent and serif headings. The table itself is the hero on the left; library and machine facts on the right. Treats the table as a craft object in a bright room.

Atelier variations

Five riffs on the chosen Atelier direction — same layout, different personality.

A2Gallery — museum minimal

Near-monochrome ink on off-white, hairline rules instead of cards, patterns listed like works in a catalogue ("№ 01", durations in minutes-primes). The quietest option.

A3Zen — Japandi calm

Cool stone and mist neutrals with a moss-green accent, soft pill shapes and generous air. Feels like a meditation app for the table.

A4Editorial — magazine spread

Oversized serif headline for the current pattern, stat rule-lines, the table framed as "Fig. 1" on the right. Terracotta + forest green on cream.

A5Nocturne — Atelier after dark

The same warm materiality flipped to espresso browns with an ember accent; the lit sand table glows against the dark room. Natural "evening mode" companion to any light variant.

A6Ceramic — bold clay

Saturated terracotta, chunky borders, tactile 3D-press buttons and playful shapes. The most personality-forward take on the craft theme.

Other directions (for reference)

BControl Room — refined dark app shell

Sidebar navigation, dense dashboard grid, monospace telemetry tiles, amber-on-slate palette, event log. Closest in spirit to the current dark UI but restructured as a proper app. Treats the table as precision hardware.

CAmbient Player — media-player metaphor

Now-drawing hero with a glowing disc, "up next" queue, circular pattern-art grid, and a fixed bottom transport bar (play/pause/skip + brightness/speed). Treats patterns like an album collection and the table like a speaker.
